Questions from brands and manufacturers

What does it cost?

Nothing in this demo. There is no account to make and no fee to list a company.

Where do the answers come from?

Only from company profiles on Meridian Loop. Every company and person in this demo is fictional; the certification schemes are real.

How are matches ranked?

By how closely a profile fits your words, then by how many of your requirements it meets: country, certificate, run size and lead time.

What if nobody fits?

It says so, shows the closest manufacturers and names the requirement each one misses.

Does it use AI?

It runs on Claude when an API key is set, and on a built-in assistant without one. Both answer only from the profiles.

Where did Meridian Loop start?

With Sustainable India, which set out in 2019 to be the bridge between manufacturers and designers.
